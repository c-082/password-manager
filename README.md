# Password Manager 🔐

A simple C# console-based password manager that stores credentials using encryption and local JSON storage.

## Features
- Add accounts with site, email, and password
- Encrypt passwords before storing them
- Persist data locally in a JSON file
- View stored accounts via the console

## Tech Stack
- C#
- .NET
- Microsoft.AspNetCore.DataProtection
- System.Text.Json
